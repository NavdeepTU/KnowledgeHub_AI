# Start KnowledgeHub AI Session

1. Read `AGENTS.md`.
2. Read `docs/PROJECT_STATUS.md`.
3. Read `docs/ROADMAP.md`.
4. Inspect the current Git status and recent changes.
5. Inspect the files relevant to the current milestone.
6. Do not modify any files yet.
7. Summarize:
   - current milestone,
   - completed functionality,
   - known limitations,
   - unfinished work,
   - the smallest useful task that can be completed in 60-90 minutes.
8. Wait for approval before implementing the task.
